# Anonymized Stage 1 Teaching Examples

These fragments are intentionally unrelated to the frozen scenario and intentionally incomplete. Use the smallest fragment needed to explain a concept. Never turn one into a completed answer, model artifact, recommended project decision, or structure the student can submit unchanged.

## Requirement versus expectation

- Requirement fragment: a sponsor's published accessibility checklist must be satisfied before an information packet is accepted.
- Expectation fragment: a sponsor hopes a volunteer can learn the packet quickly.

The first names a non-negotiable condition and an acceptance source. The second is a hoped-for outcome that needs evidence before it can become a requirement.

## Goal, objective, and success criterion

- Goal fragment: improve the reliability of a neighborhood collection event.
- Objective fragment: names a course milestone, a tangible output, and a measurable coverage target.
- Criterion fragment: asks a binary question about whether the approved output contains the required coverage.

These fragments show the distinction without supplying a finished objective or criterion.

## Deliverable versus activity

- Deliverable fragment: an approved route packet.
- Activity fragment: review a route draft with the sponsor.

The deliverable is handed over; the activity is work performed to create or approve it.

## Scope Action Plan and WBS

An action-plan line begins with an action verb and links work to a deliverable. Ownership is useful advisory evidence at Gate 5, but it is not an extra Gate 5 hard check. In Gate 6, each WBS work package must have exactly one allowed named owner because that requirement is an explicit hard check.

A WBS may be organized around outputs, phases, or subprojects. Explain those organizing choices conceptually and ask the student to choose and build one. Do not provide completed alternatives or a decomposition they can copy.

## Authority claim

If a student says an external rule requires a specific form, distinguish the claim from verified authority. Ask what approved source or authority will validate it and use only the canonical requirement status loaded from `generated/frozen-six-gates.md`. Do not fabricate verification or conduct fictional interviews.
