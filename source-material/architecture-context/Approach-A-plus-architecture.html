Glossary

Sub-agent
A specialist role the orchestrating GPT switches into for one job (grading, summarizing, simulating). One model, many hats orchestrated by protocol, not parallel processes.
Insights Agent
The interactive data agent embedded in all four advisors. Silently logs usage patterns; students and instructors can also ask it directly ("How am I using AI? Where am I over-relying?").
Auto-Grader
Sub-agent that scores work against your rubric at each stage gate and logs score + rationale. Advisory the instructor moderates.
Summarizer
Sub-agent that writes a 3-line digest per session: what the student is working on, decided, and stuck on. Feeds the dashboard.
AI-reliance index
Ratio of AI content accepted verbatim vs. challenged/modified by the student. High reliance + low critique depth = a teaching moment.
Critique depth
0–3 rating of how substantively the student pushed back on AI drafts in a session.
GPT Action
A Custom GPT's ability to call an external API, defined by an OpenAPI schema. Here: the only bridge out of ChatGPT, used for logging.
Apps Script
Google's built-in scripting for Sheets. Deployed as a web app it becomes a free, serverless webhook no hosting.
Session ID
A unique stamp on each report footer and each logged event, tying submissions to the audit trail.
Code Interpreter
ChatGPT's built-in Python runtime runs the versioned Monte Carlo script and cost math deterministically.
Codex
OpenAI's coding agent (CLI/IDE/cloud), included with ChatGPT Edu sign-in. Builds and maintains everything in the repo: prompts, Apps Script, schemas, tests.
Codex Skill
A reusable SKILL.md instruction pack Codex loads on demand. Each build task below is captured as a skill so next term's rebuild is a re-run, not a rewrite.
ChatGPT Canvas
The AI-edited side-by-side document holding the Living Project File. (Not the Canvas LMS.)
